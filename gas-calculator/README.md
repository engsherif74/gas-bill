# 🔥 حاسبة فاتورة الغاز

تطبيق ذكي ومتقن دقيق الحسابات لحساب فاتورة الغاز المصري وفقاً للشرائح السعرية المختلفة.

## ✨ المميزات

- 🎯 إدخال مباشر للاستهلاك أو إدخال بالقراءات (السابقة والحالية)
- 💰 عرض الأسعار المطبقة حالياً بضغطة زر
- 📊 تفاصيل كاملة عند الطلب (اختياري)
- 🌐 دعم اللغتين العربية والإنجليزية
- 📱 يعمل بدون إنترنت (Offline Mode)
- 🎨 تصميم عصري وسهل الاستخدام
- 🔒 جميع البيانات محفوظة محلياً - لا يُرسل أي شيء للإنترنت
- 📲 قابل للتثبيت على الجوال كتطبيق حقيقي

## 🚀 الاستخدام

افتح الرابط: `https://username.github.io/gas-calculator/`

### تثبيت كتطبيق على الجوال
- **Android (Chrome)**: اضغط على القائمة (⋮) → "إضافة إلى الشاشة الرئيسية"
- **iOS (Safari)**: اضغط على زر المشاركة → "إضافة إلى الشاشة الرئيسية"

## 📱 تحويله إلى تطبيق أندرويد APK

### الطريقة الأسهل - PWABuilder
1. ارفع الملفات على GitHub Pages
2. اذهب إلى https://www.pwabuilder.com
3. الصق رابط موقعك
4. اضغط "Package for Stores" → اختر Android
5. حمّل ملف APK

## 🛠️ التقنيات المستخدمة

- HTML5 / CSS3 / Vanilla JavaScript
- Progressive Web App (PWA)
- Service Worker (Offline Support)
- LocalStorage (لحفظ البيانات محلياً)
